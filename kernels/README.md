# TVM Generated Kernels

This directory contains CUDA kernels generated by TVM MetaSchedule for various attention operations.

## Directory Structure

- `kernels/`: All generated `.cu` files.
- `kernels/best/`: A collection of high-performing kernels that achieved speedups over PyTorch/cuBLAS.

## Best Performing Kernels

The following kernels achieved >1.0x speedup compared to PyTorch:
- **BERT 512 Projections** (`Q_proj`, `K_proj`, `V_proj`): ~1.07x speedup.
- **Llama 2048 Projections** (`Q_proj`, `K_proj`, `V_proj`): ~1.03x speedup.
- **Llama 2048 QK Dot** (`QK_dot`): ~1.05x speedup.

## Inspection

Use `inspect_attention_kernels.py` to regenerate these kernels or view their TIR schedules.
